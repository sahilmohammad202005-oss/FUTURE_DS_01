# FUTURE_DS_01
This project was completed as part of the Future Interns Data Science &amp; Analytics Internship.
#DATASET USED:
--------------
coffee shop sales from kaggle as source 

Tools Used:
-----------
* Excel Web
* Power BI

Project Tasks
-----------------
* Cleaned and organized sales data
* Analyzed revenue trends
* Identified top-performing products and regions
* Built an interactive dashboard
* Generated business recommendations

Key Insights
---------------
* Barista Espresso generated the highest revenue
* Coffee category was the most profitable
* Sales steadily increased from January to June
* Hell’s Kitchen was the top-performing region

Business Recommendations
-------------------------
* Focus on expanding coffee product sales
* Strengthen marketing in high-performing regions
* Optimize inventory using sales trends
* Improve strategies during low-sales periods
